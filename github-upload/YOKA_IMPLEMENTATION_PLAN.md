# YOKA_IMPLEMENTATION_PLAN.md — Web版 ver.0.1 実装計画

## 方針
- 見た目・配色・画面構成は既存プロトタイプを維持。旧版は `archive/prototype-2026-08.html` に保存。
- GitHub Pages でそのまま動く「ビルド不要」構成を維持（CDN + ブラウザ内Babel）。
- API・保存処理は `js/services.js` に集約し、UIから分離（将来の iOS/Android 版で同じ Supabase・同じ関数設計を再利用）。
- 実データと「サンプル」「デモ」を明確に区別。取得失敗時に架空の値を出さない。

## ファイル構成
```
index.html              CDN読込とエントリ
config.js               Supabase URL / anon key（公開前提の値のみ）
js/services.js          Supabase・地域・天気・施設・保存
js/ui.jsx               共通UI（スマホ全画面 / PCではフレーム表示）
js/app.jsx              平常モード全画面・認証・地域選択・掲載ページ・規約
js/disaster.jsx         災害モード（デモ）
supabase/migrations/001_init.sql
archive/prototype-2026-08.html
```

## ルーティング
ハッシュ方式（`#/home` `#/map?view=hazard` `#/calendar` `#/login` など）。GitHub Pages でリロード・直リンクしても404にならない。

## 外部データの選定
| 用途 | 採用 | 理由・条件 |
| --- | --- | --- |
| 市区町村一覧・コード | 国土地理院 `maps.gsi.go.jp/js/muni.js` | 全国地方公共団体コード5桁。地理院地図で使われる公的な表 |
| 市区町村の代表地点 | 国土地理院 住所検索API | 無料・キー不要 |
| 現在地→市区町村 | 国土地理院 逆ジオコーダ | 無料・キー不要 |
| 天気 | 気象庁（府県天気予報JSON・アメダス最新観測値） | 公的データ。政府標準利用規約準拠で出典明記により商用利用可。市区町村→一次細分区域は気象庁 area.json で対応付け。※当初採用の Open-Meteo は国内予報と乖離があったため置換 |
| 背景地図 | 地理院タイル（淡色地図） | 出典表示で利用可。OSM公式タイルは大量アクセス禁止のため不採用 |
| 公共施設 | OpenStreetMap（Overpass API） | ODbL。出典表示必須。公開サーバーは負荷制限あり |
| ハザード | ハザードマップポータルサイト オープンデータ（洪水・土砂3種・津波・高潮） | 国土交通省。出典表示必須 |

## STEP対応
| STEP | 実装 |
| --- | --- |
| 2 地域選択 | 都道府県→市区町村、検索、現在地。未ログインは localStorage、ログイン時は `profiles` |

| 8 チラシ | サンプル明示、指定文言、掲載問い合わせ導線 |
| 9 まち情報 | みんなのニュース廃止、サンプル2件、`local_content` テーブル設計 |
